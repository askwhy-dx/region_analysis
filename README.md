# 지역분석 대시보드

가맹 상담 자리에서 **"이 동네에 아이가 얼마나 있고, 학원·학교·경쟁사는 어디에 있는지"** 를
지도로 바로 보여주는 조회 화면입니다.

**바로가기: https://jichang999-dotcom.github.io/tes2/jiyeok/web/**

- 로그인 없이 인터넷 브라우저(크롬 권장)로 열립니다. PC·태블릿 모두 됩니다.
- 전국 → 시도 → 시군구 → 행정동(3,558개)까지 눌러 들어가며 봅니다.
- 점수나 등급을 매기지 않습니다. **판단은 상담하시는 분이 하시고, 화면은 사실만 보여줍니다.**

## 1. 이렇게 씁니다

| 순서 | 할 일 |
|---|---|
| ① | 첫 화면(전국 지도)에서 **보고 싶은 지표**를 고릅니다. 지도가 그 지표로 5단계 색칠됩니다 |
| ② | 지역을 클릭해 **시도 → 시군구 → 행정동**으로 들어갑니다. 위쪽 지역 필터로 여러 곳을 한 번에 골라 비교할 수도 있습니다 |
| ②-1 | **시군구를 2개 이상 묶어 그 안에서 동 고르기** — 위쪽 필터에서 시군구를 2개 이상 체크하고 닫거나, 지도 왼쪽 위 **[다중 선택]** 을 켜고 지도에서 시군구를 클릭한 뒤 아래 **「행정동 고르기 →」** 를 누릅니다. 고른 시군구들의 동이 한 지도에 나오고, 클릭하는 동마다 합산에 더해집니다 |
| ③ | 행정동에 들어가면 **왼쪽은 상세 지도, 오른쪽은 수치 카드**가 나옵니다 |
| ④ | 지도 위 **이름표·아이콘**으로 자사·경쟁사·학교 위치를 확인합니다 |
| ⑤ | 숫자 위에 **마우스를 올리면** 그 숫자의 뜻과 출처가 나옵니다 |

**학령인구 필터** — 기본은 3~16세입니다. **와이키즈(3~7세)**, **와이즈만(8~16세)** 버튼으로 바로 바꿀 수 있고,
나이를 하나씩 골라도 됩니다. 화면의 나이는 모두 **한국나이**입니다(8세 = 초등 1학년).

**배경 지도** — 오른쪽 위 버튼으로 `일반` / `위성` / `위성+라벨` 을 바꿉니다.
상담 장소 인터넷이 느리면, 미리 그 지역을 열고 **「미리받기」** 를 눌러 두세요.

## 2. 지도에 보이는 것

| 표시 | 무엇인가 | 조작 |
|---|---|---|
| **브랜드 이름표** (흰 바탕) | 자사(와이키즈·와이즈만)와 경쟁사 지점. 자사는 브랜드 색 테두리 | 클릭하면 지점명·주소 |
| 이름표가 **위아래로 붙어 있음** | **같은 건물**에 여러 브랜드가 입주해 있다는 뜻 | |
| **초 / 중 / 고** 동그라미 | 학교 | 동그라미 **바로 밑 숫자 = 그 학교 학생 수**. 마우스를 올리면 **학년별 학생 수와 학급 수** (예: `1학년 186명 (8학급)`) |
| 초록 점 | **시너지세권** (영어유치원) — 아래 설명 참고 | 클릭 |
| 주황 점 | 입시·보습 학원 | 클릭 |
| 보라 점 | 아파트 단지 | 클릭하면 세대수·준공연도 |

지도 위 **체크박스**로 종류별로 켜고 끌 수 있고, **경쟁사·시너지세권은 브랜드별로** 골라 볼 수 있습니다.

## 6. 볼 때 꼭 알아두실 점

| 주의 | 설명 |
|---|---|
| **학원 수 = 입시·보습 학원만** | 예체능·어학원·독서실 등은 뺀 숫자입니다 |
| **학교 학생 수는 학교가 있는 동 기준** | 다른 동에서 통학하는 학생도 포함됩니다. 그 동에 **사는** 아이 수와 다를 수 있습니다 |
| **학교 학년 합계 < 전체 학생 수일 수 있음** | 학년별 표시에서 특수·순회학급 학생은 뺐습니다 |
| **아파트 단지 일부는 지도에 표시되지 않습니다** | 원천 자료에 도로명 주소가 없어 정확한 위치를 찍을 수 없는 단지(전체의 0.7%)는 **엉뚱한 곳에 찍지 않고 뺐습니다**. 아파트 세대수·매매가 수치에는 그 단지도 들어가 있습니다. 광산구 삼도동·본량동 등 9개 동은 이 때문에 지도에 단지 표시가 없습니다 |
| **지도 위 학교 숫자와 오른쪽 카드를 더해서 맞추지 마세요** | 지도 숫자는 학년별 합(특수·순회 제외)이고, 오른쪽 `초·중 재학생 수` 는 전체 학생 수입니다. 지도에는 고등학교도 나오지만 카드에는 초·중만 들어갑니다 |
| **"0개"는 빈칸이 아니라 실제로 없음** | 경쟁사 0, 학원 0은 조사 결과 없다는 뜻입니다 |
| **유치원·어린이집 원아는 선택 나이만** | 기본 3세부터라 0~2세 영아와 혼합반은 빠집니다 |
| **평당가 "표본 부족"** | 최근 2년 아파트 거래가 10건 미만인 동은 숫자를 보여주지 않습니다(대표성이 없어서) |
| **인구 증감 "–"** | 최근 1년 사이 동이 나뉘거나 새로 생긴 곳은 증감을 계산하지 않습니다(분동 때문에 인구가 급증한 것처럼 보이는 것을 막기 위해) |
| **아파트 거주 비율 100% 초과 동** | 신축 아파트 입주 전이거나 동 경계가 최근 바뀐 곳입니다. 이런 동은 **이웃 동과 함께** 보시면 정확합니다 |
| **경쟁사 정보는 홈페이지 기준** | 홈페이지에 아직 안 올라온 신규 지점이나 늦게 내려간 폐점 지점은 한 달 정도 차이가 날 수 있습니다 |

⚠️ **이 화면은 인터넷에 공개된 주소입니다.** 경쟁사도 볼 수 있으니 내부 판단 메모 등을 화면에 덧붙여 공유하지 마세요.
