## 규칙

- **화면·데이터 범위가 바뀌면 루트 `README.md`(사업부용)도 같이 고친다** — 비기술 언어로.
- **수치를 고칠 때는 산출물과 문서를 같이 고친다.** 문서에 박힌 숫자가 산출물과 다르면
  다음 사람이 어느 쪽을 믿을지 판단할 수 없다.
- **정의를 바꾸면 "옛 산출물과 비교 금지"를 명시한다.** 2026-08-03 학원 수 정의 변경
  (전 분야 → 입시·보습)처럼, 기준이 바뀌면 증감이 아니라 정의 차이가 찍힌다.
- `archive/` 는 옛 조사본 보관용이다. 현행본은 `지역분석_데이터소스_조사.xlsx` 하나뿐이다.
